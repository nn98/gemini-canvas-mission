# AI 사용 일지

- ## 4️⃣ 페어 프롬프트 릴레이 앱 `프로젝트 회고 보드`

## 1. 초기 프롬프트
``` 
단체의 구성원들이 함꼐 활용하는 게시판 형식의 웹앱 생성해줘.

같은 활동을 하고 회고를 남길거고 

서로의 회고를 공유하고 비교분석하고 상호작용할 수 있어야 해.

HTML, CSS, JS로만 한정한다.
```
1. ### 목표 사용자
   - 단체(우테코)의 구성원(크루)들
2. ### 핵심 기능 1개 이상
   1. 같은 활동을 하고 회고 기록
   2. 서로의 회고 공유
   3. 서로의 회고 비교분석
   4. 상호작용
3. ### 금지하거나 제한할 구현 조건
   - HTML / CSS / JS 로 제한

## 2. 프롬프트 개선 과정

1. ### **프롬프트 작성 방식**

   - [글렌](https://github.com/nn98)은 큰 사이클
     - 하나의 데모 생성
     - 오류/수정/개선 포인트 정리
     - 하나의 프롬프트에 종합해서 재생성
     - 반복
     - 장점 
       - 코드 생성 대기시간 감소
       - 통합적인 테스트로 숨은 버그 감소
     - 단점 
       - 사이클 진행 소모시간 증가
       - 포인트 유실 방지를 위한 주기적 기록 필요
   - [캐리](https://github.com/tjdakf)는 작은 사이클
     - 하나의 데모 생성
     - 오류/수정/개선 포인트 탐색
     - 해당 포인트 수정 해 재생성
     - 반복
     - 장점
       - 테스트 소모시간 감소
       - 즉각적인 버그 대응
     - 단점 
       - 코드 생성 대기시간 증가
       - 포착되지 않은 버그 잔존 ~ 전파 가능
   - 각 방식의 장단점을 비교, 상황에 맞춰 유동적으로 활용 시 효과적이라 합의.  
    문제 발생 가능성이 낮을 경우(최초 생성 / 부분적 수정 완료 상태) 큰 사이클,  
    문제 발생 가능성이 높을 경우(교차 검증을 통해 수정할 부분이 식별) 작은 사이클

2. ### **프롬프트 작성 근거**

   - `💡 프롬프트 작성 팁` 활용, 
     1. 초기 요청에선 구체적으로 설명,  
     2. 부분적 개선과 점진적 개선
     3. 생성된 결과물을 분석해 동작/오류의 흐름을 파악
   - 위 내용을 토대로 구체적이고 효과적인 프롬프트 작성

3. ### **프롬프트 작성 중점**

- 중점은 정상 동작이 아닌 비정상 동작에 대한 대응이라 생각
- 생성 결과물에 오류가 오작동이 발생했을 때, 
  - 단순히 틀린 부분, 수정할 방향성만 지정하지 않고
  - 그 오류나 오작동이 발생한 원인, 즉 그렇게 생성된 이유를 묻고 
  - 오류는 그 오류가 재발하지 않도록 명시  
  - 의도의 오인은 사용자의 의도를 명시 
- 체감상 수정 결과물의 품질이 양호

## 3. 효과적이었던 프롬프팅 전략
- ### **유관 기능은 묶어서**
  - 사용자 인증 기능을 도입할 때 게스트 로그인 기능을 함께 
  - 게시글 태깅 기능을 도입할 때 태그별 분류 기능을 함께 
  - 탭 간 이동 기능을 도입할 때 포커스 전환 기능을 함께

- ### **재시도는 최대 2번**
  - 네트워크 에러 등 프롬프트와 무관한 오류가 아닐 경우, 생성 오류의 원인은 프롬프트 속에 있다 
  - 같은 프롬프트도 잘게 쪼개서 하나씩 시도하다 보면, 생성 오류를 유발하는 부분을 찾을 수 있다
  - 그 부분이 남아 있는 이상 갑자기 생성 오류가 해결될 가능성은 전무하다 보고, 재시도는 단 한 번만

## 4. 배운 점

- ### **죽쑤던 바드는 어디가고**
    - 기초 상식질문도 대답못하던 바드가 어느새 미리보기 렌더링까지 원큐에 해결할 정도로 발전했나
- ### **교차 검증의 중요성**
    - 대상을 바라보는 관점이 하나만 늘어도 수많은 개선점과 숨은 오류를 파악할 수 있다
- ### **API 적용도 깔끔하게**
  - 이전까지 활용했던 LLM 기반 툴들은  
    틀은 잘 짜도 복합적인 기능이나 외부 API 참조에선 터져나가기 일수였지만  
  - 제미나이 자체적인 AI 툴 도입은 단 한 번만에 깔끔하게 적용이 가능
- ### **복잡/대용량/누적 프롬프트는 아직?**
  - 예상 외로 테코톡 활용 학습 앱이 가장 큰 문제 유발.
  - 재생 목록 전체를 한 번 만에 요약하리라 기대하진 않았지만  
    이런 당혹스러운 결과를 마주할 줄은 상상치 못함
